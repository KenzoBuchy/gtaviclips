gtaVI_clips — Privacy Policy

Last updated: November 17, 2026

1. Overview

gtaVI_clips is a personal tool that runs locally on its operator's computer. It does not collect data from the general public and has no user accounts, advertising or analytics.

2. Data accessed from TikTok

When the account owner authorizes the app, it receives from TikTok:

  • basic account information (user.info.basic: open ID, display name);
  • an access token and a refresh token, used only to upload videos to the account's drafts (video.upload).

3. How data is used

This data is used exclusively to upload clips to the authorized account's TikTok drafts. It is never sold, rented or shared with third parties, and never used for advertising or profiling.

4. Storage and security

Tokens are stored only on the operator's local computer, in a file with restricted permissions. No TikTok data is sent to any server other than TikTok's own API.

5. Video processing

Videos processed by the app are the operator's own or authorized content. To select highlights, the text transcript of a video may be sent to an AI provider (Anthropic API); no TikTok account data is included in this processing.

6. Retention and deletion

Data is kept only as long as the app is authorized. Revoking access in the TikTok app (Settings and privacy → Security → Manage app permissions) invalidates the tokens; the local files can be deleted at any time.

7. Children

The app is not intended for children and does not knowingly process data from minors.
